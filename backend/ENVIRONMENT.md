# 本地运行环境变量

启动 Java 后端前，在 IDE 运行配置或终端中设置以下环境变量：

- `DB_PASSWORD`：本机 `word_db` 账号密码
- `WECHAT_APPID`：微信小程序 AppID
- `WECHAT_SECRET`：微信小程序 AppSecret

可选变量：

- `DB_URL`：默认连接 `jdbc:mysql://127.0.0.1:3306/word_db`
- `DB_USERNAME`：默认为 `word_db`
- `SERVER_PORT`：默认为 `8081`

请勿将真实密码或 AppSecret 写入此文件、提交记录或截图。
